# Scope

## User Roles

### Student
- Register/login and manage profile.
- View personalized and general news feed.
- Read announcements and news.
- Like/unlike posts.
- Add, edit, and delete own comments.
- Search posts and announcements.
- Receive push notifications.
- Manage notification preferences.

### Faculty/Staff
- View campus content.
- Create announcements if granted publisher permissions.
- Moderate comments where authorized.
- Receive notifications.

### Administrator
- Manage users and roles.
- Create, edit, publish, archive, and delete news.
- Create urgent announcements.
- Moderate comments and reports.
- Send targeted or broadcast notifications.
- View basic system activity and audit logs.
