| Primary Users | Students, faculty/staff, administrators |

## Summary

Campus News & Announcement System is a complete full-stack campus communication platform. The Flutter app provides the student-facing experience, while a Node.js REST API handles authentication, business logic, news, announcements, comments, likes, profiles, search, and notifications. MySQL stores persistent relational data, Redis provides caching, Docker standardizes the development environment, and Obsidian serves as the project's knowledge base.
