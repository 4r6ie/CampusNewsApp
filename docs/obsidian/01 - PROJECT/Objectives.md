# Objectives

- Centralize official campus news and announcements.
- Provide a fast, mobile-first Flutter experience on Android/iOS.
- Allow students to react to and comment on posts.
- Notify users about urgent or relevant announcements.
- Provide searchable campus information.
- Create a maintainable REST API and relational data model.
- Use Redis for caching and performance-sensitive operations.
- Use Docker so the development environment is reproducible.
- Maintain project requirements, architecture, decisions, and bugs in Obsidian.
- Establish a phased development process from planning to deployment.
