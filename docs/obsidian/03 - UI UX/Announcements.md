# Announcements

## Screen Purpose
Dedicated view for official campus notices.

## Elements
- Priority badge (urgent = red, high = orange, medium = blue, low = gray)
- Pinned/urgent announcements at top
- Title, body, publisher, published date, expiry date
- Pull-to-refresh

## States
- No announcements empty state
- Loading skeleton
- Network error + retry
