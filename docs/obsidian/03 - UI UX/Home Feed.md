# Home Feed

## Screen Purpose
Primary content surface — paginated campus news and updates.

## Elements
- Pull-to-refresh
- Post cards (author avatar, title, body preview, category badge, timestamp)
- Like + comment action buttons with counts
- Pagination (infinite scroll or next page)
- Category filter tabs (All, News, Events, Academic)

## States
- Loading (skeleton shimmer)
- Empty feed message
- Network error + retry
