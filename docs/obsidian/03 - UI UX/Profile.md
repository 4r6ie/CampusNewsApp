# Profile

## Screen Purpose
View and edit student profile information.

## Elements
- Avatar (upload from gallery/camera)
- Full name, student number, course, year level
- Bio text area
- Edit / Save toggle
- Notification preferences link
- Logout button

## States
- View mode (read-only)
- Edit mode (form inputs)
- Save success/error feedback
