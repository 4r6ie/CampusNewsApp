# Design System

## Colors

- Primary: `#5E35B1` (light) / `#7C4DFF` (dark)
- Secondary: `#00BFA5` / `#64FFDA`
- Error: `#B00020` / `#EF9A9A`
- Surface: White / `#1C1C1E`

## Typography

Google Fonts — Inter (regular, medium, semibold, bold)

## Spacing

8px base unit. Card padding: 16px. Screen margin: 16px.

## Components

- `AppCard` — rounded card (borderRadius: 16)
- `AppButton` — filled/outline/ghost variants
- `AppTextField` — filled input (borderRadius: 12)
- `SkeletonLoader` — shimmer placeholder
- `EmptyState` — illustration + message
- `ErrorState` — retry prompt
