# Search

## Screen Purpose
Keyword and filter search across posts and announcements.

## Elements
- Search input (auto-focus, clear button)
- Debounced search (300ms)
- Filter chips: Posts, Announcements
- Results list with post/announcement cards
- Pagination
- Empty results state

## States
- Loading
- No results found
- Network error
