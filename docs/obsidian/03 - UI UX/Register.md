# Register

## Screen Purpose
Create a new student account with campus email, password, full name, and course.

## Elements
- Email input (validated)
- Password input (min 8 chars, show/hide toggle)
- Full name input
- Course / program selector (optional)
- Year level selector (optional)
- Sign Up button
- "Already have an account? Sign In" link

## States
- Loading, validation error, duplicate email error, success
