# Version 1.0

## Feature Scope (MVP)

- News feed
- Campus announcements
- Student profiles
- Likes
- Comments
- Search
- Push notifications
- Admin content management
- Comment moderation
- Reports
- Redis caching
- Dockerized backend
- Testing and bug tracking
- Obsidian project documentation

## Success Criteria

Students can reliably log in, browse official campus news and announcements, interact through likes/comments, search content, maintain profiles, and receive notifications. Admins can safely publish and moderate content. Backend stack reproduces via Docker with clear Obsidian documentation.
