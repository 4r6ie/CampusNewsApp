## Tech Stack

| Layer | Technology |
|-------|-----------|
| Mobile/UI | Flutter + Dart |
| State | Riverpod |
| Networking | Dio |
| Routing | go_router |
| Backend | Node.js + TypeScript |
| API Framework | Express |
| Validation | Zod |
| ORM/Access | Prisma schema + raw mysql2 |
| Database | MySQL 8 |
| Cache | Redis (ioredis) |
| Push | Firebase Cloud Messaging |
| Containers | Docker + Compose |
| Documentation | Obsidian vault |
