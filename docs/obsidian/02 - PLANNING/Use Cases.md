# Use Cases

| Use Case | Actors | Trigger | Flow |
|----------|--------|---------|------|
| Login | Student, Faculty, Admin | App launch | Enter credentials → receive tokens → access protected features |
| View Feed | Student | Home screen | Browse paginated posts → like/comment |
| Publish Announcement | Admin, Publisher | Admin dashboard | Compose → set priority → publish → notification sent |
| Search Content | Student | Search screen | Enter query → view filtered posts and announcements |
| Moderate Content | Admin | Reports page | Review report → hide/remove/comment → log audit |
