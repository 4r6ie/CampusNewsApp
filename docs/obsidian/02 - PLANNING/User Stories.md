# User Stories

## Authentication
- As a student, I want to register with my campus email so I can access the system
- As a student, I want to log in securely without re-entering credentials often

## News Feed
- As a student, I want to browse campus news so I stay informed
- As a student, I want to refresh the feed to see new posts

## Engagement
- As a student, I want to like posts to show support
- As a student, I want to comment on posts to discuss topics
- As a student, I want to delete only my own comments

## Announcements
- As a student, I want to see urgent announcements prominently displayed
- As an admin, I want to publish announcements for all students

## Notifications
- As a student, I want push notifications for urgent announcements
- As a student, I want to control which notifications I receive

## Profile
- As a student, I want to view and edit my profile information
